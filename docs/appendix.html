Facilitator Reference: The Session Template

Each session in this book follows a consistent structure. When you’re building or adapting new sessions, use this template.

Standard 2-hour format

Block Time Purpose
Check-in 15 min Re-establish safety; read the room
Education block 35 min Short teaching + facilitated discussion
BREAK 10 min Non-negotiable decompression
Support / story block 45 min Personal sharing and group response
Close & bridge 15 min Takeaway, seed question, next session

Adding a podcast episode

Each session page has an audio section at the top. To link your MP4 episodes:

  1. Upload your MP4 file to your GitHub repository under assets/audio/session-XX.mp4

  2. Replace the [⬇ Download MP4](#) placeholder link with the actual GitHub raw file URL:

    https://raw.githubusercontent.com/YOUR-USERNAME/cynics-guide/main/assets/audio/session-01.mp4

  3. Rebuild and push the site.

Hosting on GitHub Pages

This site is built with Quarto and hosted free on GitHub Pages.

Initial setup

  1. Create a GitHub account if you don’t have one
  2. Create a new repository named cynics-guide-to-church (or similar)
  3. Upload all files from this project
  4. In repository Settings → Pages → Source: select Deploy from branch → main → /docs
  5. Your site will be live at https://YOUR-USERNAME.github.io/cynics-guide-to-church

Updating the site

To rebuild after making changes:

quarto render

Then commit and push the updated docs/ folder to GitHub.

Updating the _quarto.yml

Replace YOUR-USERNAME in _quarto.yml with your actual GitHub username once the repo is created.
